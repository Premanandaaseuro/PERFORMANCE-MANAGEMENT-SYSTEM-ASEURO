# Test Coverage Matrix - Performance Management System (PMS)

This document provides the full end-to-end testing matrix covering functional, UI, API, database, role-based security, responsive viewports, and accessibility scenarios.

| Module | Feature | Role | Positive Cases | Negative Cases | UI Cases | API Cases | Database Cases | Permission Cases | Automation Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Auth** | Multi-Role Login | HR, Manager, Employee | Valid credentials login & proper dashboard redirection | Invalid credentials, blank input, trailing whitespace, special characters | Input masking, password toggle button, company header, error alert box | POST `/api/auth/login` token generation & status validation | Session creation & failed attempt counter updates | Role-specific dashboard route redirection | **Automated** (`auth.spec.ts`, `api-endpoints.spec.ts`) |
| **Auth** | Security Injection | Anonymous / Attacker | Neutralized string inputs | SQL injection payloads, XSS `<script>` injections | Alert message visible without executing scripts | Malformed payload handling (400/401/500 safe rejection) | No unauthorized record mutation | Reject access for unauthenticated users | **Automated** (`auth.spec.ts`, `rbac.spec.ts`) |
| **HR** | Dashboard Overview | HR | Load stats & KPI metrics | API failure handling & empty states | Stat cards, review banners, action links | GET `/api/hr/dashboard` | Verify counts match active DB records | Accessible only by HR role; 403 for Manager/Employee | **Automated** (`hr-workflow.spec.ts`, `api-endpoints.spec.ts`) |
| **HR** | Employee Directory | HR | View employee directory, search employee by name | Non-existent employee query returns empty state | Table headers, search box, action buttons | GET `/api/hr/employees` | Cross-check `employees` table | Manager/Employee blocked from HR directory | **Automated** (`hr-workflow.spec.ts`, `api-endpoints.spec.ts`) |
| **HR** | Add Employee | HR | Create new employee with manager & department | Empty mandatory fields, duplicate email/code | Form inputs, dropdown selectors, error toasts | POST `/api/hr/employees` | Insert into `employees` table | Only HR can create employees | **Automated** (`hr-workflow.spec.ts`) |
| **HR** | KPI Master Management | HR | Create master KPI, assign weightage & designation | Weightage sum mismatch, blank names | Modal dialog, save button, weightage slider | GET/POST/PUT `/api/hr/kpis` | `kpi_master` table insertion & update | Forbidden for Manager/Employee | **Automated** (`hr-workflow.spec.ts`) |
| **HR** | PMS Lifecycle & Rating Gate | HR | Evaluate employee after manager review, finalize cycle | Attempting to rate before manager submits review | Manager-pending banner, disabled HR inputs, recalculate score | POST `/api/hr/lifecycle/finalize` | `pms_assignments` and `pms_history` state transition | HR ratings disabled until Manager review is complete | **Automated** (`hr-workflow.spec.ts`) |
| **HR** | Overall Cycle Reports | HR | View cycle report table, download Excel & PDF | Missing cycle month returns all | Tab switcher, cycle selector, download buttons | GET `/api/hr/reports/cycle/view`, `/excel`, `/pdf` | Read aggregation from `pms_assignments` | Accessible only by HR | **Automated** (`hr-workflow.spec.ts`, `api-endpoints.spec.ts`) |
| **Manager** | Dashboard & Teams | Manager | View team list and pending review counts | No assigned employees empty state | Stat badges, team table | GET `/api/manager/dashboard` | `employees` where manager_id matches | Isolated to Manager's direct reports | **Automated** (`manager-workflow.spec.ts`) |
| **Manager** | KPI Review & Scale (1-5) | Manager | Submit rating between 1.0 and 5.0 with comments | Entering rating 0.0 or <1.0 or >5.0 | Number inputs (min=1, max=5), validation error box | POST `/api/manager/pms/{id}/submit` | Update `employee_kpi_ratings` manager fields | Excludes HR-exclusive assessment KPIs | **Automated** (`manager-workflow.spec.ts`) |
| **Employee** | Dashboard & My KPIs | Employee | View active cycle KPIs, fill self-rating (1.0-5.0) | Rating 0 or out-of-range inputs | KPI cards, weightage, save draft button | GET `/employee/pms/dashboard`, PUT `/draft` | Update `employee_kpi_ratings` self fields | Employee cannot see other employee ratings | **Automated** (`employee-workflow.spec.ts`) |
| **Employee** | Appraisal History | Employee | View past finalized PMS cycles & grades | No history state | History list, download report link | GET `/employee/pms/history` | Read from `pms_history` table | Scoped strictly to logged-in employee | **Automated** (`employee-workflow.spec.ts`) |
| **Security** | Role-Based Access Control | All Roles | Enforce proper route & API permissions | Direct URL tampering, IDOR cross-access | Redirection to `/unauthorized` or `/login` | 401/403 HTTP status codes returned | Zero unauthorized read/write mutations | Strict RBAC guards on both frontend & backend | **Automated** (`rbac.spec.ts`) |
| **Responsive**| Viewport Adaptation | All Roles | Render cleanly on Desktop, Laptop, Tablet, Mobile | Layout breakage or overlapping elements | Viewports: 1920x1080, 1366x768, 1280x720, 768x1024, 390x844 | N/A | N/A | Consistent across devices | **Automated** (`responsive.spec.ts`) |
| **A11y** | Accessibility Scan | All Roles | Clean WCAG compliance | Missing form labels or accessibility violations | Axe-core accessibility scan on login & pages | N/A | N/A | Keyboard & screen-reader friendly | **Automated** (`accessibility.spec.ts`) |
