# Shared Components & Utilities

## Overview
This directory contains cross-cutting, reusable TypeScript types, shared constants, and pure utility functions shared across frontend and backend modules.

## Components Included
- **`types/`**: Common TypeScript domain interfaces (`User`, `PmsAssignment`, `PmsKpi`, `EmployeeKpiRating`, `FinalPmsResult`)
- **`constants/`**: Roles (`ROLE_EMPLOYEE`, `ROLE_MANAGER`, `ROLE_HR`) and PMS state enums
- **`utilities/`**: Pure functions (`calculateWeightedOverallScore`, `derivePerformanceGrade`)
